Mémo :

**VBA** signifie **Visual Basic for Applications**.

C'est un **langage de programmation Microsoft**, issu de la famille Visual Basic, intégré à des applications hôtes comme Excel, Word ou Access.

Son rôle principal est d'automatiser et de piloter ces applications : répéter des actions, appliquer des règles, transformer des données ou produire des livrables sans tout faire manuellement.

Une application hôte expose au code VBA ses fonctionnalités sous forme d'objets et d'API.

- **Application hôte** : logiciel dans lequel le code VBA s'exécute.
- **API** : interface qu'un logiciel expose pour permettre à du code d'utiliser ses fonctionnalités.
- **Objet** : élément manipulable exposé par l'application hôte (un classeur, une feuille, une cellule...).
- **Modèle objet** : organisation de l'ensemble de ces objets, par exemple classeurs, feuilles, cellules, graphiques ou tableaux croisés dynamiques.

Dans ce cours, l'application hôte principale est Excel. Excel intègre VBA depuis Excel 5.0, sorti en 1993.

**Anecdote/tips :** VBA est aujourd'hui considéré comme **legacy**. Microsoft continue de le maintenir (il reste présent et fonctionnel dans Excel, Word, Access...), mais ne le fait plus évoluer vers de nouvelles plateformes : il est absent ou très limité sur Office Web et sur Mac. Les nouveaux développements d'automatisation Office sont désormais orientés vers les **Office Add-ins** (API JavaScript multiplateforme), présentés par Microsoft comme la voie d'avenir. VBA reste néanmoins massivement utilisé dans l'existant, notamment en entreprise.
